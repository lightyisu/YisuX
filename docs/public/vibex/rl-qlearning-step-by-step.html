从零搭一个强化学习：不用任何现成的环境和库，只用 Python，从一条 5 格的走廊开始，每一步只加一小块东西，跑通了再走下一步。五步走完，就亲手搭出了一个完整的 Q-learning。

每一步都按同一个节奏走：加一点东西 → 跑一下看结果 → 发现问题 → 下一步解决它。

1　搭环境，让它乱走环境
2　加一张记分表Q 表
3　每走一步，更新记分表核心
4　偶尔乱试ε-greedy
5　每次只改一点学习率 α

第 1 步　搭一个环境，让智能体乱走

环境是一条 5 格的走廊，“人”从位置 0 出发，宝藏在位置 4：

人0
1
2
3
宝4

规则只有三条：

  • 每次只能往左或往右走一格；
  • 最左边是墙，往左撞墙就原地不动；
  • 走到宝藏奖励 1，这一局结束；其他情况奖励 0。

代码里要写的就是一个函数 next_step(位置, 动作)，告诉智能体“你走到了哪、拿到多少奖励、结束没有”。智能体这时什么都不会，每一步都抛硬币：

Python
action = random.choice([0, 1])    # 0 往左，1 往右，纯乱走
state, reward, done = next_step(state, action)

明明 4 步就够，它每局都要走二十几步，次数每次都不一样。

环境 = next_step，状态 = 位置 0～4，动作 = 左/右，奖励 = 0 或 1，策略 = “抛硬币”。强化学习要做的，就是把“抛硬币”换成“聪明地走”，后面四步都在做这件事。

第 2 步　加一张记分表（Q 表），先只看不学

要变聪明，它得记住东西。5 个位置 × 2 个动作，就是一张 5 行 2 列的表，叫 Q 表。一开始什么都不知道，全是 0：

位置往左往右
00.000.00
10.000.00
………

然后把策略从“抛硬币”改成“查表，哪个分高走哪个，一样高才抛硬币”。

还是乱走，跑完表也还是全 0。

这是故意的：表里全是 0，左右永远一样高，每次都落到“抛硬币”；而且没有任何代码在改这张表。智能体有了记事本，但还没往上写东西。

第 3 步　每走一步，更新记分表

先试最直接的想法：拿到多少分就记多少分

每走一步，把这一步的奖励记到“刚才的位置、刚才的动作”那一格；连续玩 6 局，每局后看一眼表。

Python
Q[state][action] = reward

6 局下来只有“位置 3 往右”变成了 1，其他全是 0，步数忽多忽少，没有变好。

只有位置 3 往右能直接拿到奖励。位置 2 往右奖励是 0，就被记成 0，可它其实是好的，因为它走到了离宝藏只差一步的地方。只看眼前奖励，就看不到“走到一个好位置”本身的价值。

加上“走到的位置有多好”

改成：这一步的分数 = 这一步的奖励 + 新位置里最好的那个分数，再打个 9 折。游戏结束了就没有“以后”，后半截记 0。

Python
Q[state][action] = reward + gamma * max(Q[next_state])   # gamma = 0.9

“往右”那一列每局往回传一格：

往右的分位置 0位置 1位置 2位置 3
第 1 局后0.000.000.001.00
第 2 局后0.000.000.901.00
第 3 局后0.000.810.901.00
第 4 局后0.730.810.901.00

位置 2 往右会到位置 3，位置 3 最好能拿 1，打 9 折记 0.9；位置 1 再打 9 折记 0.81……从第 5 局起，每个位置都是往右分高，智能体每局直接走 4 步到宝藏。它学会了。

“奖励 + 打折后的未来最好分”就是新估计，也就是贝尔曼方程的思想；那个 0.9 就是折扣因子 γ，越远的奖励越不值钱。把 γ 改成 0，就又退回到只记眼前奖励的版本。

“往左”那一列一直是 0。它一发现往右好，就再也不往左走了。

第 4 步　偶尔乱试一下（ε-greedy）

改地图，让它“上当”

原来的走廊只有一条路，看不出问题。现在在最左边放一个小宝藏（0.1 分），人改从位置 1 出发：

小宝0
人1
2
3
大宝4

往左 1 步就能拿小宝藏；往右 3 步拿大宝藏，打折后仍值 0.81 分，正确答案是往右。学习方法不变，玩 100 局，记下每局拿到的是哪个。

很可能 100 局全是“小”。

第 1 局碰巧往左拿到小宝藏，位置 1 往左就记成 0.1，往右还是 0。从此它每次都往左，永远不知道右边还有大宝藏。（如果第一局碰巧往右走到了大宝藏，结果会不一样，多跑几次就能看到。）这就是只利用、不探索：吃过一家还行的餐厅，就再也不试别家了。

一半时间随便走

选动作时先掷个骰子：有 ε 的概率不看表、随便走（探索），其他时候照表走（利用）。

Python
if random.random() < epsilon:         # epsilon = 0.5
    return random.choice([0, 1])

某次运行，每 20 局里拿到大宝藏的次数：

局数1–2021–4041–6061–8081–100
大宝藏1031313

最后位置 1 往右（0.81）超过了往左（0.10），它终于发现了大宝藏。训练时还会偶尔拿小宝藏，是因为一半时间在乱走；所以训练完把 ε 设成 0 再测试，路线就是直接往右 [1, 2, 3, 4]。

ε 控制试新路的比例。改成 0.1，乱试太少，很难碰巧连走 3 步到大宝藏；改成 1，一直乱走，成绩很差。试得太少找不到好路，试得太多浪费时间。

第 5 步　每次只改一点点（学习率 α）

让大宝藏“看运气”

到目前为止，每次更新都把旧分数整个覆盖掉。现在把大宝藏改成一半概率 2 分、一半概率 0 分，平均还是 1 分，往右仍然是对的。训练 300 局。

“位置 3 往右”的分数在 2 和 0 之间来回跳。最后一次刚好开出 0，它就认定往右是 0 分；测试时在位置 2 和 3 之间来回打转，永远走不到宝藏（所以测试要加步数上限）。

整个覆盖，就只记得最近一次的运气，以前的经验全忘了。就像一家餐厅吃了 10 次都不错，最近一次踩雷，就再也不去了。

只往新结果挪 10%

算出新估计后不直接替换，而是先算“和旧分数差多少”，再只挪一小部分：

Python
new_estimate = reward + gamma * max(Q[next_state])
td_error = new_estimate - Q[state][action]
Q[state][action] += alpha * td_error   # alpha = 0.1

比如旧分数 1.0：开出 2 分，差 +1，挪 10% 变 1.1；下次开出 0 分，差 −1.1，挪 10% 变 0.99。分数在 1 附近小幅波动，相当于对很多次结果取平均。

“位置 3 往右”稳定在 1 左右，每个位置都是往右更高，测试路线回到 [1, 2, 3, 4]。

“新估计和旧分数差多少”就是 TD 误差，挪多少就是学习率 α。这三行合起来，就是完整的 Q-learning 公式：

公式
Q(s, a) ← Q(s, a) + α × [ r + γ × max Q(s′) − Q(s, a) ]
  • r + γ × max Q(s′)：新估计，第 3 步加的
  • 方括号整体：TD 误差，新估计减旧分数
  • α：学习率，第 5 步加的

步骤加了什么解决了什么
1环境和规则有了状态、动作、奖励，但只会乱走
2Q 表 + 按表选动作有地方记分了，但还不会往里写

这就是一个完整的强化学习过程

最基础的东西都在里面了：环境、状态、动作、奖励、回合、策略、价值函数 Q、折扣 γ、探索与利用、新估计 → TD 误差 → 用 α 更新、先训练再测试，全都在这几十行里。几乎所有强化学习算法都是这个流程，区别只在“怎么记分”和“怎么更新”。

它覆盖的是基础，还没涉及的扩展方向：

  • 泛化（DQN）：Q 表只能记有限个状态。把表换成神经网络，用 TD 误差当损失来训练，核心逻辑不变。
  • 直接学策略（策略梯度、PPO）：直接学“每个动作选的概率”，适合机械臂转角这类连续动作。
  • 先学环境再规划（AlphaZero 一类）：利用或学习环境规则，在“脑子里”推演。

记住这句话就够了：

和环境交互 → 拿到奖励 → 用“奖励 + 对未来的估计”修正自己 → 重复。
